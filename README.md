# Termux Bot

Private Discord Bot for the [Termux Discord Server](https://discord.gg/HXpF69X)

Written in TypeScript using [discord.js](https://discord.js.org) and [Sapphire](https://sapphirejs.dev)

## Running

Copy `.env.example` to `.env` and fill in the fields.

```
$ pnpm install
$ pnpm run migrate
$ pnpm run build
$ pnpm start
```
